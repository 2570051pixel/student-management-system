# Student Management System
A Spring Boot REST API for managing student records with CRUD operations.
## Features
- Add a new student
- Get all students
- Get student by ID
- Update student details
- Delete a student
## Technology Used
- Java
- Spring Boot
- Spring Data JPA
- Hybernate
- MySQL
- Maven
## API Operations
| Method | Endoint | Description |
|---|---|---|
| POST |'/students' | Add anew student |
| GET | '/students' | Get all students |
| GET | '/students/{id}' | Get students by ID |
| PUT | '/students/{id}' | Update students |                                                     
| DELETE | '/students{id}' | Delete student |
